# 安全モデル

## 信頼境界

MCPクライアントとLLMは、ローカル実行であっても信頼済みとはみなしません。すべての引数を検証し、公開済みツールの範囲外へ到達できない構造にします。

## 多層停止

優先順位の高い順に、次の停止経路を設けます。

1. ユーザー専用のローカル緊急停止キー
2. 実キーボード・マウス入力による人間の上書き
3. クライアントtickのSafety controller
4. `emergency_stop` MCPツール
5. 操作リース満了による自動解放

ローカル停止はHTTP、LLM、Voice Chat、routine状態に依存せず動作させます。

## 即時停止条件

- Minecraftのウィンドウがフォーカスを失った
- GUI、チャット、メニューが開いた
- ワールドから切断、dimension移動、再スポーン、クライアント終了が始まった
- プレイヤーが死亡・行動不能になった、または体力が設定閾値以下になった
- Voice Chatのミュートが解除された、または状態を確認できなくなった
- MCP heartbeatまたは操作リースが期限切れになった
- 予期しない対象、位置ずれ、インベントリ変化、一定時間進捗なしを検出した
- ユーザーの実入力、緊急停止キー、ローカルUIのlockを検出した
- 例外、キュー飽和、tick遅延、adapter互換性エラーが発生した

停止処理では、全キーとマウス操作を解放し、routineを終端状態にし、所有している場合だけVoice Chat状態を復元します。

## 能力境界

### 許可

- 通常入力で可能な移動、視点、ジャンプ、攻撃、使用、ホットバー選択
- 同期済みの自分の状態、インベントリ、クロスヘア対象の読み取り
- 許可リスト化された有限ルーチン

### 禁止

- 任意パケット、任意チャット、任意コマンド、任意Java呼び出し
- 座標・速度・NBT・インベントリの直接変更
- 壁越し、未ロード領域、サーバー内部情報の取得
- リーチ・視線・クールダウン・採掘速度・移動速度の回避
- 自動ログイン、認証情報の取得、Discord操作
- プレイヤーへの攻撃、窃盗、取引、蘇生など対人影響のある自動操作

## ネットワーク

- bind先は文字列ではなくloopback addressとして`127.0.0.1`へ固定する。
- `0.0.0.0`、LAN IP、IPv6全公開へのフォールバックは禁止する。
- `Origin`がある場合は明示的allowlistと照合し、不正なら403にする。
- 256bit以上のランダムBearerトークンを初回生成し、ログやMCPレスポンスへ出さない。
- リクエストサイズ、JSON深度、文字列長、同時数、毎秒回数に上限を設ける。
- `/mcp`以外の管理エンドポイントを設けない。状態確認もMCPツール経由で認証する。

## 監査ログ

残すもの:

- 時刻、routine ID、ツール名、検証結果、状態遷移、停止理由
- Minecraft/NeoForge/MOD/adapterのバージョン
- 操作時間、進捗指標、例外の要約

残さないもの:

- Bearerトークン、Microsoft認証情報、サーバーアドレス
- 音声、チャット本文、Discord内容
- 端末の音声デバイス名や不要な個人情報

## 運用上の注意

- unattended運転は初期段階では禁止し、ユーザーが画面を監視できる時間に限定する。
- マルチプレイでは接続先のルール、負荷制限、公平性に合わせて利用者が設定する。
- サーバーから切断された場合や制限に抵触する兆候を検出した場合は即時停止する。
- 特定サーバーだけを許可する仕組みは実装せず、シングルプレイでも同じ機能を使えるようにする。
