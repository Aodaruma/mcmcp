# MCMCP NeoForge — 導入ガイド

Minecraftのプレイヤーを、CodexやClaude CodeなどのMCPクライアントから操作するクライアント専用MODです。MCPサーバーはMinecraft内で動作します。Minecraftサーバー側へのMOD導入や、別の中継プログラムは不要です。

**Minecraft / Mojang / Microsoftの公式製品ではありません。**
NOT AN OFFICIAL MINECRAFT MOD. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

## 対応環境・同梱物

- Minecraft **26.2** / NeoForge **26.2.0.59** / Java **25**
- 同じPC上で動作するCodex、Claude CodeなどのMCPクライアント
- 配布版：**0.1.0-SNAPSHOT / 2026-09-05 ロボットアイコン版**（開発版）
- `mcmcp-neoforge-26.2-0.1.0-SNAPSHOT.jar`：通常プレイ用MOD本体
- `README.md`：この導入ガイド

## 1. MODを導入する

1. Minecraftを終了します。
2. ZIPを展開し、同梱のJARを使用するMinecraftの`mods`フォルダーへ入れます。
   Prism Launcherの場合は、対象の起動構成を右クリックし、「編集」→「MOD」から追加できます。
3. 更新の場合は、古いMCMCP JARを`mods`の外へバックアップしてから差し替えます。同じMODのJARを複数入れないでください。
4. Minecraftを起動し、ワールドまたはサーバーへ入ります。

既存の設定ファイルと認証情報はそのまま引き継げます。

## 2. MCPクライアントを接続する

1. ワールド内で`Esc`を押します。
2. MCP操作がOFFの状態で「MCP接続設定」を開きます。
3. 「Codexを自動設定」または「Claude Codeを自動設定」を選びます。
4. 表示される設定ファイルの変更先を確認して「OK」を押します。
5. 対象のMCPクライアントを完全に終了し、起動し直します。

自動設定はCodexの`~/.codex/config.toml`、Claude Codeの`~/.claude.json`を更新します。既存の設定ファイルは初回に`.mcmcp.bak`としてバックアップします。接続に必要な認証情報は自動で読み込まれます。

接続先は既定で **`http://127.0.0.1:8765/mcp`** です。同じPCから接続してください。Claude Code用の自動設定を、Claude Desktopの設定として使用することはできません。

## 3. 操作をONにする

1. ゲーム内の「MCP操作: OFF」を押し、「MCP操作: ON / 待機中」にします。
2. マルチプレイで警告が表示された場合は、サーバーの規約と管理者の許可を確認して「ONにする」を選びます。「次回からこの警告を表示しない」は、その接続先を記憶する場合に選んでください。
3. 「ゲームに戻る」でメニューを閉じます。
4. MCPクライアントへ、まず次のように依頼します。

```text
MCMCPで現在の状態と所持品を確認してください。まだ行動は開始しないでください。
```

状態を取得できたら、具体的な短い作業から依頼してください。ワールドへ入り直した場合は、改めてMCP操作をONにします。

## ロボットアイコンの見方

通常のゲーム画面では右下にアイコンが表示され、メニューでは状態の文字も表示されます。

| 表示 | 状態 |
| --- | --- |
| 灰色・目を閉じたロボット | OFF |
| オレンジ・目を開けたロボット | ON／待機中 |
| 水色・顔が「…」のロボット | ON／推論中（評価機能の使用時） |
| 青色・顔が「▶」のロボット | ON／実行中 |
| 紫色・顔が盾のロボット | ON／緊急回避中 |
| 緑色・顔が「？」のロボット | 攻撃確認中 |
| 赤色・顔が「！」のロボット | FAULT／接続機能または内部の異常 |

実行中に`Esc`を押すと自動操作を緊急停止します。MCP操作自体を無効にするには、メニューのMCP操作ボタンを押してOFFにしてください。

## 接続できないとき

- **ツールが表示されない**：Minecraftを先に起動し、MCPクライアントを再起動してください。
- **接続拒否**：Minecraftが起動しているか確認してください。複数の起動構成でMCMCPを同時起動すると、同じポートを使用できません。
- **`401 Unauthorized`**：別の起動構成の認証情報を参照していないか確認してください。現在使用する起動構成から接続設定を行ってください。
- **`InvalidToolCall`**：古いJARが残っていないか確認し、このZIPのJARへ差し替えてMinecraftを再起動してください。この版にはCodexの呼び出し付加情報への互換修正が含まれます。
- **タイトル画面にボタンがない**：ワールドへ入ってから`Esc`を押してください。
- **設定の競合が表示される**：以前に手動登録した`mcmcp`設定がある場合、自動設定では上書きできないことがあります。既存設定をバックアップし、接続先を確認してください。

認証情報は、使用するゲームフォルダーの`config/mcmcp/mcp-token`に保存されます。このファイルや実際のトークンを、配布ZIP・チャット・問い合わせ用ログへ含めないでください。
