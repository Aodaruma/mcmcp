# 2026-10-11 公開API v2: 看板文字・任意NBT

Issue #84 / Draft PR #85。チャット対応 `81927ca` の後続。`agent_get_observation` に看板文字と `include_nbt:boolean`（既定false）を追加した。公開ツール数は16個。[使い方・範囲・上限](../PUBLIC_API_V2_SIGN_NBT_20261011.md) を参照。通常「くらふとぶ！」には導入していない。

## 実装と回帰検証

保持済みframeの地形情報に、応答時点で再検証した可視ブロックのclient情報を補足する。任意座標探索、server NBT照会、NBT書込みは追加しない。看板とNBTは未信頼データで、文字列を実行しない。NBT省略・取得不可・上限超過を区別する。

看板を読み取る観測要求は、描画済みの正確なplayer tickに対応する霧情報を使えるpre-tickへ配送する。post-tickではplayer tickが進むため、見える看板も再検証に失敗することを隔離実機で再現し修正した。既存のsession・停止epoch・deadline・配送放棄の後処理を維持する。ネイティブ文字フィルターは、filtered_messagesが省略された場合の通常messagesへのフォールバックも含めて適用する。
