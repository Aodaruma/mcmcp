# 2026-10-11 公開API v2: チャット送受信・prefix/suffix

Issue #84 / Draft PR #85。`agent_chat` を1つ追加し、公開ツールは16個。使い方は [チャット仕様](../PUBLIC_API_V2_CHAT_20261011.md)。既存branch `a8174a1` の後続として実装した。通常「くらふとぶ！」への導入は行っていない。

## 実装

- `operation:read` はMCP ON中にネイティブのチャット表示キューへ採用された文章を、world sessionごとに最大256件保持。独立カーソルで非破壊読取りする。本文は未信頼のデータとして返し、命令として実行しない。
- `operation:send` は共通jobの受付・配送確認・取消・入力解放を経由し、通常のネイティブ送信を一度だけ呼ぶ。送信先への到達や既読は保証しない。コマンド、改行、不正Unicode、過長入力を拒否し、1秒に1試行まで。
- 「設定 → チャット設定」の最下部へAgent専用のprefix/suffixを追加。各々ON/OFFと文字列編集が可能。既定はprefix OFF・空、suffix ON・` (by Agent)`。手動チャットは変更しない。設定を受付時に確定し、付加後も最大256 UTF-16単位を検査する。
- 通常の履歴消去とworld変更で古いカーソルを破棄し、公開エラー `INVALID_CURSOR` を返す。単なる受信取得の待機をAgent作業中と扱わず、手動入力の停止条件へ混ぜない。
