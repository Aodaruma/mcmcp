# MCMCPのライセンス案

2026-09-05時点の提案です。採用・設定変更はまだ行っていません。

現状は `gradle.properties` の `mod_license=All Rights Reserved` がMOD情報に反映され、リポジトリ直下にLICENSE本文はありません。OSSとしての利用条件は設定されていません。

## 第一候補：MIT

MCMCPをMODパックへ同梱しやすくし、修正・移植・再利用も広く歓迎する方針ならMITをおすすめします。著作権表示とライセンス文を残せば、再配布・改変・商用利用ができる短いライセンスです。改変版のソース公開は義務ではなく、有料販売や非公開の派生版も認める点が判断の分かれ目です。[MIT本文と要点](https://choosealicense.com/licenses/mit/)

| 候補 | 向いている方針 | 主な違い |
| --- | --- | --- |
| **MIT（推奨）** | 導入・再利用のしやすさを優先 | 短い。著作権・ライセンス表示を維持。改変ソースの公開義務なし |
| **Apache-2.0** | 企業利用や貢献者からの特許許諾を明確にしたい | 明示的な特許許諾と特許訴訟時の終了条項。変更表示や該当するNOTICEの維持などが必要 |
| **MPL-2.0** | 再配布される改良部分を公開してほしい | 対象ファイル単位のコピーレフト。配布時は対象ソースの提供方法を案内。無関係な新規ファイルまで同じ条件にする必要はない |

比較の出典：[Apache-2.0本文](https://www.apache.org/licenses/LICENSE-2.0)、[Mozilla公式MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/)。

## 採用するときの変更範囲

選んだライセンス本文をルートのLICENSEへ追加し、著作権者の表記を確定します。`mod_license`、READMEの案内、配布ZIP・JARに含めるライセンス文も揃えて再ビルドします。他の作者から取り込んだコードがあれば、変更可能な範囲と元の表示も確認します。

README中のCurseForge公式画像、Minecraft・Prismの画面に含まれる第三者の素材は、MCMCPのライセンスで再許諾する対象に含めません。各権利者の権利を維持し、出典を明記します。試作ロゴの採用・利用条件もコードとは別に決められます。

「派生版の公開も必須にしたい」ならMPL-2.0を再検討し、それ以外はMITで始めるのが扱いやすいと考えます。
