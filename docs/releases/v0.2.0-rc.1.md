## 日本語

公開API v2へ移行するリリース候補です。座標・数量を指定する17ツール、軽い既定観測、共通jobの進行・結果・取消、有限scriptとJSON/CSV設計図をまとめました。

**対象：Minecraft Java Edition 26.2 / NeoForge 26.2.0.59 / Java 25。クライアント側専用、MPL 2.0。**

### 0.1系からの移行

旧agent_start_action／公開JSON Action DSLは置き換わります。更新後にMCPクライアントを再起動し、配布ZIPのPUBLIC_API.mdから新しいツールを使ってください。

### 主な変更

- 移動、範囲破壊・設置、収納・クラフト、論理入力、chatと設計図を共通jobへ接続。結果不明の開始操作を自動再送せず、既知IDで取得します。
- 既定stateをプレイヤーと手元9枠中心に整理。最新観測の原子的な選択、ページcursorの解放、返却済みframeの有界な保持を追加しました。
- レバーの希望状態が成立済みなら操作を省略。変更時はserverの結果を照合します。有限の反復入力と明示要求の手持ち詳細も追加しました。
- 共通Menu収納に接続し、検証済みSophisticated Backpacksの同種バッグを区別して指定数を移送できます。
- レシピ参照を「解放済み／すべての作成可能」で切替可能にしました。追加同期が不完全な場合や、自動craft未対応のレシピはその状態を返します。
- Windowsの接続設定をプロファイルごとに診断し、分離Codex設定を生成できます。別profileの参照を上書きせず、設定が別processにロックされていてもゲームを待たせません。
- 緊急回復の弓の取消・発射例外でも入力解放を完了します。
- 狭い岸への飛行救助で、現在の可視支持・接地後停止までを検証します。検索時間切れ時には安全を証明できた有限coastを使い、元の救助予算を維持します。
- 梯子付近の横移動では現在の実体位置から通過軌道を検証し、塞がった軌道を選びません。

導入には添付ZIPを使用してください。本体JAR、画像付き導入ガイドPDF/Markdown、公開API v2ガイド、ライセンス、ソース取得先とチェックサムを同梱しています。

### 確認範囲

[最終統合試験と復旧記録](https://github.com/Aodaruma/mcmcp/blob/v0.2.0-rc.1/docs/experiments/20261115_release_rc1.md)を参照してください。JAR hash、対象commit、自動試験と実機の範囲、残る課題を記録します。

救助は有限の時間・移動・カメラ予算に従います。着地後に追加の敵が混入した試験では距離予算を使い切っており、任意の複合危険で救助の完遂を保証しません。

梯子の横移動で今回見つけた現在位置の軌道不具合（#98）は修正・実機確認済みです。梯子全般（#81）の全配置や、旧DSLの坑道専用Action（#21）は完了とは扱いません。旧PR #83／#26は未合格のケースを残すためDraftを維持しています。追加レシピ同期では材料・設備の可用性評価が未対応です。共通収納は接続契約と検証済み構成に従い、任意のMODや独自upgrade slotへ自動対応するものではありません。Codex設定のconfiguredは参照診断で、クライアント自身の通信成功は別途確認します。

## English

This release candidate introduces public API v2: 17 coordinate/count-based tools, compact default observations, shared job progress/results/cancellation, bounded scripts, and JSON/CSV blueprints.

Requires Minecraft Java Edition 26.2, NeoForge 26.2.0.59 and Java 25. Client-side only; MPL 2.0.

The old agent_start_action/public JSON Action DSL is replaced. Restart your MCP client after updating and follow PUBLIC_API.md in the distribution ZIP. Confirmed effects remain in partial results, and uncertain actions are never blindly retried.

It also verifies visible landing support and stopping footprints during flight rescue, preserves bounded recovery budgets, and checks gap trajectories from the actual current pose.

It includes atomic latest observations and bounded frame retention, cursor release, desired-state lever interaction, bounded repeated input, explicit held-item details, verified shared-menu storage, scoped recipe lookup, and profile-aware Windows MCP configuration. Additional recipe sources report incomplete coverage and unsupported crafting separately.

See the linked final validation record for exact artifacts, tests, restoration and remaining limitations. Recovery remains bounded by its original budgets; an additional unplanned enemy encounter exhausted the distance budget in one preserved negative run. Generated configuration status does not prove the MCP client's own connection.
