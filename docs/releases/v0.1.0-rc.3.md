## 日本語

地上絵の施工に使われた建築・補充・進捗保存の機能をまとめたリリース候補です。コンテナ操作、描画待ち、移動・端設置の停止処理も改善しました。

**対象：Minecraft Java Edition 26.2 / NeoForge 26.2.0.59 / Java 25。** クライアント側だけに導入します。ライセンスはMPL 2.0です。

- 導入には `mcmcp-neoforge-26.2-0.1.0-rc.3.zip` を使用してください。MOD本体、画像付きREADME.md/PDF、操作ガイド、ライセンスとチェックサムを同梱しています。JARとPDFも個別に添付しています。
- 通常のVanilla full cube、階段、非double slab、pane、床置き松明など、検証した建材familyへ対応範囲を拡大しました。通常のfull cubeは所持品から設置用の材料参照を取得でき、見本ブロックが不要です。
- `extend_known_floor`で、Shiftによるかがみ移動と水平1マスの端設置に対応しました。元の支持との重なりを保ち、設置結果と材料消費を確認してから新しい床へ進みます。
- [平面施工runner](https://github.com/Aodaruma/mcmcp/tree/v0.1.0-rc.3/tools/building)は最大128×128の設計図、材料補充、松明配置、進捗の保存・再開を扱います。PowerShell 7.4以上とタグ付きソース内のツールが必要です。runnerは配布ZIPのMODだけでは起動しません。結果不明の操作を勝手に再送せず、ワールド再読込み時には利用者の明示的な確認を要求します。
- チェストからの移送でhotbarが埋まった後も、安全なMAIN_HANDで通常の開封・読み戻しを続けられるよう修正しました。銅チェストにも対応し、inspectの完全な結果を取得できます。
- 部分成功した移送は、確認済みの個数と再観測が必要なことを返します。失敗したActionをそのまま再実行せず、新しい観測から残りを計画できます。
- 描画情報の一時欠測を元の期限内で待機し、再確認後に操作します。既知の水源での移動・岸への復帰を追加しました。移動と端設置の入力期限が切れた場合は停止し、段階や遅延時間の診断を残します。

利用者から地上絵の完成報告を受けています。公開MCPによる施工と外部runner・進捗台帳を使った運用実績であり、全工程を無介入で完遂したfreshモデル評価の認定ではありません。

**検証：** Java 1,344件（通常1,304、harness 13、admin bridge 27）、配布ツール3件、Python通信14件、施工・capabilityの模擬試験が成功。隔離Dockerでは版付きJARを使い、最大896個のチェスト→樽移送、銅の大チェスト74個の往復、47個の部分成功から残り64個の再開と111個の収納を確認しました。端設置・補充・保存再開・水中移動の既存実機記録も照合しています。[検証範囲と証跡](https://github.com/Aodaruma/mcmcp/blob/v0.1.0-rc.3/docs/experiments/20260922_release_rc3.md)を参照してください。

**制限：** 全Vanilla特殊ブロックやMOD追加ブロックへの包括対応ではありません。待機中にモンスターへ自動対処する機能はありません。低FPS・CPU停滞・追加MODの独自interactionによって安全停止する場合があります。進捗保存は操作結果不明や別ワールドへの自動復旧を保証しません。未統合の連続坑道掘削・長押し拡張は含みません。

## English

This release candidate brings together construction, material refills and persistent progress used for a completed ground-art project. It also improves container operations, bounded renderer recovery and movement/edge-placement shutdown.

**Requires Minecraft Java Edition 26.2, NeoForge 26.2.0.59 and Java 25.** Client-side only; MPL 2.0.

- Download the ZIP for the mod, illustrated Japanese guide, action guide, licenses and checksums. The JAR and PDF are also available separately.
- Adds audited Vanilla building-material families, placement references from owned ordinary full cubes, and bounded crouched edge extension.
- The [PowerShell building runner](https://github.com/Aodaruma/mcmcp/tree/v0.1.0-rc.3/tools/building), available in the tagged source and requiring PowerShell 7.4+, supports blueprints up to 128×128, refills, torches and persistent checkpoints. It does not replay unknown operations or silently resume across world sessions.
- Fixes safe MAIN_HAND container reopening after hotbar-filling transfers; adds copper chests, complete inspection results and explicit confirmed-prefix/reobservation information after partial transfers.
- Adds observed-water navigation and shore return, bounded renderer recovery, and diagnostics for expired movement and floor-extension input leases.

Ground-art completion is user-reported operational evidence involving public MCP operations and external progress tooling, not certification of a fully unattended fresh-model run. Validation includes 1,344 Java tests, three packaging tests and isolated in-game regressions for 896-item transfers, copper chests and partial-transfer recovery. See the [verification record](https://github.com/Aodaruma/mcmcp/blob/v0.1.0-rc.3/docs/experiments/20260922_release_rc3.md).

Not every Vanilla special block or modded block is supported. Idle mode does not automatically fight hostile mobs. Low FPS, CPU stalls and custom mod interactions can still cause safe failures. Unknown outcomes require reconciliation. Unmerged tunnel-mining and held-input extensions are excluded.
