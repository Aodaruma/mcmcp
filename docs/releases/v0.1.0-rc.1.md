## 日本語

MCMCPの初回公開リリース候補です。AIクライアントから、自分のMinecraftプレイヤーを通して周囲観測、移動、チェスト棚卸し、アイテム整理、農作業などを行えます。

**対象：Minecraft Java Edition 26.2 / NeoForge 26.2.0.59 / Java 25。** クライアント側だけに導入します。ライセンスはMPL 2.0です。

- 導入には `mcmcp-neoforge-26.2-0.1.0-rc.1.zip` をダウンロードしてください。MOD本体、画像付きREADME.md/PDF、操作ガイド、ライセンスとチェックサムを同梱しています。
- JAR単体とREADME.pdfも添付しています。画像付きガイドにはCurseForge・Prism Launcherでの導入とMCP接続手順があります。
- MCP操作のONはAction終了後も維持します。実行中はEscで緊急停止できます。
- チェスト検査結果は全品目を保持し、複数コンテナの結果をページ単位で取得できます。
- fog情報が欠けたときに周囲観測が空になる経路、額縁が多い場所の照準候補選択、角度丸めによる縁への引っかかりを修正しました。照準失敗時には固定分類の診断を返します。
- タグからJAR・PDF・ZIPを生成して公開するCIを導入しました。PDF生成にTyporaは不要です。

**既知の制限：** 額縁付きチェストの追加修正は自動テスト済みですが、報告された倉庫での再確認はまだです。以前のJARでは294収納を確認できた一方、立ち位置・左右halfの変更が必要な照準失敗が残っていました。低FPS時の安定性、追加MODとの互換性、未探索エリアや段差移動、大規模建築などは引き続き改善中です。

ローカル検証：unit 1,111件、harness 13件、admin bridge 21件の計1,145件が成功。公開前のCIでもテスト、開発用MODの混入検査、PDF・ZIP検証を実行します。

## English

The first public release candidate of MCMCP. AI clients can use your Minecraft player to observe the surroundings, navigate known paths, inspect chests, organize items, and perform supported farming and building tasks.

**Requires Minecraft Java Edition 26.2, NeoForge 26.2.0.59, and Java 25.** Install on the client only. Licensed under MPL 2.0.

- Download `mcmcp-neoforge-26.2-0.1.0-rc.1.zip` for the mod, illustrated README in Markdown/PDF, action guide, licenses, and checksums. The JAR and PDF are also attached separately. The illustrated guide is in Japanese.
- MCP control stays ON between actions. Press Esc to stop an active action.
- Container inspection retains complete item counts and supports paging through multiple container results.
- Fixes address missing fog samples, nearby item frames being omitted by the observation cap, and aim points near outline edges affected by angle rounding. Failed aiming now includes a fixed crosshair classification.
- Tagged CI builds publish matching JAR, PDF, and ZIP files. PDF generation does not require Typora.

**Known limitations:** The latest item-frame chest fixes pass automated tests, but have not yet been rechecked in the reported warehouse. The previous JAR completed a 294-container inventory with some aiming failures requiring a different standing position or chest half. Low-FPS stability, compatibility with additional mods, exploration and full-block steps, and large building jobs remain in progress.

Local validation: all 1,145 tests passed (1,111 unit, 13 harness, 21 admin bridge). CI repeats the tests and verifies production JAR isolation, PDF output, and distribution ZIP contents before publication.
