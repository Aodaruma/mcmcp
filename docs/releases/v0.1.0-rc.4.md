## 日本語

指定した個数の収納移送に対応し、Codexとの接続、クラフトの描画待機、インベントリ画面の例外を修正したリリース候補です。

**対象：Minecraft Java Edition 26.2 / NeoForge 26.2.0.59 / Java 25。クライアント側専用、MPL 2.0。**

- `take_known_container_stack` / `store_known_container_stack` に任意の `transfer_count` を追加しました。例えば「今回2個だけ取り出す」を指定でき、絶対目標個数が既に満たされていても指定量を移送します。省略時は従来のスタック単位移送を維持します。
- Codexが付けるsessionId/windowIdの相関metadataを限定的に受理し、正常なTool呼出が拒否される問題を修正しました。
- クラフト前の一時的な描画情報欠測を元の期限・予算内で待ち、再検証してから通常操作を行います。
- プレイヤーのインベントリ画面を開いた際、型を持たないmenuの取得で発生する例外を修正しました。
- MOD収納は、専用の移送エンジンを増やさず共通Menu基盤へ接続する設計方針を整理しました。**バックパック等の操作対応そのものは今後の実装です。**

導入には添付ZIPを使用してください。本体JAR、画像付き導入ガイドPDF/Markdown、Action DSLガイド、ライセンス、ソース取得先とチェックサムを同梱しています。

**検証：** Java 1,362件、配布ツール3件、Python通信14件と施工・capability模擬試験を通過。隔離Dockerで指定量の移送12操作、既存の最大896個移送・銅チェスト往復10操作、インベントリ開閉を確認しました。通常登録接続と描画回復を伴うクラフトの既存実機記録も照合しています。[検証範囲と証跡](https://github.com/Aodaruma/mcmcp/blob/v0.1.0-rc.4/docs/experiments/20260926_release_rc4.md)を参照してください。

斜めだけで接する足場の新しい経路対応、レシピ範囲の拡張、任意MODの収納・固有操作はこの版に含みません。待機中のモンスターへの自動対処や、結果不明の操作の自動再送も行いません。

## English

This release candidate adds exact-count container transfers and fixes Codex correlation metadata, bounded crafting renderer recovery, and an exception when opening the player inventory.

Requires Minecraft Java Edition 26.2, NeoForge 26.2.0.59 and Java 25. Client-side only; MPL 2.0.

- Optional `transfer_count` moves the requested amount even when the absolute inventory/container goal is already met. Omitting it preserves whole-stack behavior.
- Accepts bounded Codex session/window correlation metadata.
- Waits for missing crafting renderer evidence within the original deadlines, then revalidates before interaction.
- Handles the untyped player inventory menu without throwing.
- Documents a generic storage integration direction; modded backpack interaction is not implemented by this release.

Validation: 1,362 Java tests, packaging and transport tests, 12 exact-transfer and 10 legacy-transfer Actions in an isolated game, plus inventory screen checks. See the [verification record](https://github.com/Aodaruma/mcmcp/blob/v0.1.0-rc.4/docs/experiments/20260926_release_rc4.md) for evidence and limits.

Corner-touching diagonal path support, broader recipe coverage and arbitrary mod-specific actions are not included. Idle mode does not fight mobs, and unknown outcomes are not blindly retried.
