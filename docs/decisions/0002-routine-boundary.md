# ADR 0002: LLMにはルーチンAPIだけを公開する

- 状態: 採用
- 日付: 2026-08-19

## 決定

本番モードのMCPでは`hold_forward`や`hold_attack`のような生の入力ツールを公開せず、許可リスト化された有限ルーチンだけを公開します。

## 理由

- LLM応答遅延とMinecraftの20 tick/s制御を分離できる。
- 時間・対象・停止条件をルーチン単位で検証できる。
- 通信断やLLM停止時にも短い操作リースで安全に解放できる。
- MCP tool surfaceを小さくし、監査とテストを現実的に保てる。

## 影響

- 新しい作業ごとに決定論的ルーチンの実装と試験が必要。
- 柔軟性は下がるが、予測可能性とサーバー上の公平性を優先する。
- 低レベルプリミティブは開発診断用の厳格なdeveloper modeに限る。
