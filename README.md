# Minecraft NeoForge MCP Automation

Minecraft 26.2 / NeoForge 26.2向けに、通常のサバイバル操作だけを使う汎用クライアント自動化をMCP経由で制御するための設計リポジトリです。シングルプレイとマルチプレイの両方を対象とし、「くらふとぶ！ v01.2」を最初の互換性確認環境にします。

## 結論

技術的には実現可能です。まず次の条件を満たすPoCから始め、シングルプレイ、検証用マルチプレイ、任意の対応サーバーへ段階的に広げます。

- サーバー側MOD、OP権限、独自パケットを使わないクライアント専用MOD
- LLMは計画と監督のみ。毎tickの操作はローカルの決定論的ルーチンが担当
- 通常プレイヤーが見えている情報と、通常の移動・攻撃・使用操作だけを利用
- Simple Voice Chatは自動化中にミュートし、終了時に元の状態を安全に復元
- ローカル緊急停止、短い操作リース、切断・死亡・フォーカス喪失時の即時停止
- 127.0.0.1限定、Origin検証、Bearerトークン付きのMCPエンドポイント
- ローカルワールドと複製したPrism Launcherインスタンスで安全性を確認してからマルチプレイへ導入

現時点は設計確定段階で、実行可能なMODはまだ含まれていません。

## 対象バージョン

| 項目 | 確認値 |
|---|---|
| Modpack | くらふとぶ！ v01.2 |
| Minecraft | 26.2 |
| NeoForge | 26.2.0.59 |
| Java | 25.0.1 LTS |
| Simple Voice Chat | 2.6.22+26.2 |

これらは最初の互換性確認に使ったPrism Launcherインスタンス、導入済みJAR、起動ログから確認した固定値です。自動化MOD自体は特定サーバーへ依存させず、ベースModpackも自動更新しません。

## 最初の実装範囲

Phase 1は読み取り専用MCPと緊急停止、Phase 2はその場から動かない丸石製造機の採掘ルーチンだけを実装します。GUI操作、建築、農業、経路探索、Baritone連携は、基礎の安全性を確認するまで対象外です。

## 絶対に実装しないもの

- テレポート、飛行、リーチ延長、壁越し判定、隠れたブロックやエンティティの取得
- クリエイティブ相当のアイテム生成、任意パケット送信、任意コマンド・チャット送信
- サーバーのアンチチートや権限判定の回避
- 任意Javaクラス呼び出し、reflection、スクリプト実行をMCPへ公開する機能
- ユーザーの緊急停止や実入力を無視する自動化

## Ponytailについて

PonytailはMinecraftやMCPの実行依存にはしません。将来の実装レビューで「既存機能・標準機能を優先し、必要最小限にする」という判断補助としてのみ利用します。安全境界、検証、エラー処理は簡略化の対象外です。
